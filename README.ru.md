# SCALEGO

SCALEGO — локальное приложение для Windows, в котором можно увеличивать, сжимать, сравнивать и экспортировать изображения. Оно сочетает обычное масштабирование с необязательным AI-увеличением и выполняет обработку на компьютере пользователя.

> Текущий выпуск: [v0.3.0-alpha.1](https://github.com/Oceannin/SCALEGO/releases/tag/v0.3.0-alpha.1).

## Возможности

- Три сценария: увеличить, увеличить и сжать либо сжать без изменения размеров.
- Сравнение с перетаскиваемым разделителем, режимы «Оригинал» и «Результат», масштаб «Вписать» и 1:1, изменение масштаба колёсиком мыши и выбор подложки предпросмотра.
- Рабочая область до 200 изображений; обработку и экспорт можно применять к текущему выделению.
- Пять встроенных AI-профилей, а также Lanczos и Nearest для увеличения без AI.
- Экспорт в PNG, JPEG, WebP и AVIF с настройками качества, режима без потерь, прозрачности и ограничения веса там, где их поддерживает выбранный формат.
- Русский и английский интерфейс, переключатель языка в приложении и сохранение выбранного языка.
- Светлая и тёмная темы, восстановление очереди, локальное хранение сессии и рецепты обработки `.scalego` рядом с экспортированными изображениями.

## Рабочий процесс

1. **Добавьте** одно или несколько изображений кнопкой «Добавить», через диалог выбора файлов или перетаскиванием.
2. **Настройте** выбранные изображения: укажите «Увеличить», «Увеличить и сжать» или «Сжать», затем выберите доступные для этого сценария масштаб, метод, модель, формат и параметры экспорта.
3. Нажмите **«Обработать»**. Если изменить параметры после получения результата, он станет устаревшим, а основной кнопкой снова будет «Обработать».
4. **Сравните** оригинал и результат с помощью разделителя, масштаба и выбора подложки.
5. **Сохраните** готовый результат. Для одного изображения используется «Сохранить». При работе с несколькими файлами «Сохранить выбранные» экспортирует выбранные готовые результаты, а «Сохранить все» — последний готовый результат для каждого исходника.

Исходные файлы не перезаписываются. Если папка результата ещё не выбрана, SCALEGO предложит выбрать её при сохранении.

## AI-модели и методы увеличения

В Windows-пакеты входят оба нативных Vulkan-движка и все пять профилей моделей. В исходном checkout runtime отсутствует: команда `npm run engine:install` скачивает закреплённые официальные архивы и проверяет их SHA-256.

| Профиль | Для чего подходит | Движок / модель | Нативный масштаб | Доступный масштаб |
| --- | --- | --- | --- | --- |
| Фото · Естественно | Более мягкая и естественная детализация фото | Real-ESRGAN / `realesrnet-x4plus` | 4× | 2×, 3×, 4× |
| Фото · Детально | Более выраженная детализация фото | Real-ESRGAN / `realesrgan-x4plus` | 4× | 2×, 3×, 4× |
| Иллюстрация · Чистые линии | Чёткие линии и подавление шума | Real-CUGAN SE, denoise3 | 2×, 3×, 4× | 2×, 3×, 4× |
| Иллюстрация · Детально | Детализированные рисунки и аниме | Real-ESRGAN / `realesrgan-x4plus-anime` | 4× | 2×, 3×, 4× |
| Быстро | Быстрый предпросмотр и лёгкая графика | Real-ESRGAN / `realesr-animevideov3` | 2×, 3×, 4× | 2×, 3×, 4× |

Профили с нативным масштабом 4× формируют результат 2× и 3× через запуск нативной модели и одно уменьшение Lanczos. AI может реконструировать мелкие детали, а не сохранять их буквально, поэтому перед экспортом стоит проверить текст, лица, тонкие линии и прозрачность. Альфа-канал масштабируется отдельно от RGB.

Lanczos и Nearest работают без AI-runtime. Технические подробности приведены в [аудите моделей и лицензий](docs/MODEL_AUDIT.md) и [описании нескольких движков](docs/MULTI_ENGINE.md).

## Скачивание и установка

SCALEGO предназначен для Windows x64. Опубликованные версии доступны в виде Portable-файла и установщика NSIS в [GitHub Releases](https://github.com/Oceannin/SCALEGO/releases). Сборки не имеют цифровой подписи.

Для AI-увеличения нужны совместимый Vulkan GPU, актуальный графический драйвер и [Microsoft Visual C++ Redistributable x64](https://learn.microsoft.com/ru-ru/cpp/windows/latest-supported-vc-redist). Сжатие, Lanczos и Nearest не требуют AI-движков. Пакеты для macOS и Linux не предоставляются.

## Форматы и ограничения

- Поддерживаются статичные PNG, JPEG, WebP и AVIF; анимация, RAW и видео не поддерживаются.
- Размер одного исходника — до 200 МБ и 40 мегапикселей. Результат — до 100 мегапикселей и 32 768 пикселей по каждой стороне; доступная память может снизить практический предел.
- Режим «Увеличить» всегда создаёт PNG без потерь. Режимы «Увеличить и сжать» и «Сжать» позволяют выбрать PNG, JPEG, WebP или AVIF.
- JPEG всегда сохраняется с потерями и заменяет прозрачность выбранной подложкой. WebP и AVIF поддерживают экспорт с потерями и без потерь. PNG с потерями использует сокращение палитры и может изменить цвета и значения альфа-канала.
- Ограничение веса подбирает качество без уменьшения разрешения и не гарантирует достижение заданного размера. В режиме без потерь лимит только проверяется, качество не снижается.
- Результат сохраняется в sRGB, 8 бит на канал. EXIF и исходный ICC-профиль не переносятся.

## Разработка

Требования: Windows x64, Node.js 24, npm и интернет для установки зависимостей и необязательного AI-runtime. API-ключ и файл `.env` не нужны.

```powershell
git clone https://github.com/Oceannin/SCALEGO.git
cd SCALEGO
npm ci
npm run engine:install
npm run dev
```

`npm run dev:web` открывает React-интерфейс без Electron; обработка файлов доступна только в Electron. Для работы без AI пропустите `engine:install` и выберите Lanczos, Nearest или только сжатие.

Перед pull request выполните поддерживаемые проверки:

```powershell
npm run typecheck
npm test
npm run build
npm run smoke
npm run smoke:queue
npm run smoke:models
```

После установки runtime команда `npm run dist:win` собирает Portable- и NSIS-пакеты для Windows. Она создаёт только локальные артефакты и ничего не публикует. Подробности упаковки и расширенные проверки описаны в документе [«Разработка»](docs/DEVELOPMENT.md).

| Путь | Назначение |
| --- | --- |
| `src/` | React-интерфейс, локализация, темы и UI-контракты |
| `electron/` | Основной процесс Electron, IPC, очередь, кодеки, AI-движки и экспорт |
| `scripts/` | Разработка, установка runtime, упаковка и smoke-проверки |
| `tests/` | Тесты обработки, движков, очереди и экспорта |
| `docs/` | Пользовательская, архитектурная, проверочная и лицензионная документация |
