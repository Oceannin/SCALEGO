# Участие в SCALEGO

Спасибо за интерес к проекту. Полезнее всего сейчас воспроизводимые ошибки обработки, примеры проблемных краёв и проверка разных Vulkan GPU.

## Ошибки и идеи

Используйте [шаблоны issues](https://github.com/Oceannin/SCALEGO/issues/new/choose). Опишите задачу, ожидаемый результат и то, что произошло. Для ошибки приложите версию Windows, GPU/драйвер, версию SCALEGO, параметры обработки и безопасный тестовый файл. Не публикуйте личные снимки, токены, содержимое профиля приложения или закрытые материалы.

Уязвимости обсуждаются по [отдельному процессу](SECURITY.md).

## Изменения кода

1. Начните со [сборки из исходников](docs/DEVELOPMENT.md).
2. Делайте небольшие изменения вокруг одной задачи; для крупного изменения сначала обсудите поведение в issue.
3. Сохраните изоляцию renderer/main, проверку IPC и защиту исходных файлов.
4. Проверьте `npm test` и `npm run build`. Для изменения интерфейса приложите снимки; для кодеков — воспроизводимый тест. Если Vulkan недоступен, явно укажите, что AI не проверялся.
5. Опишите проблему, новое поведение и проверки в pull request. Обновите пользовательскую документацию, если изменился рабочий процесс.

Не добавляйте модели, зависимости или изображения без источника и понятных условий распространения. Не коммитьте `runtime/`, `release/`, тестовые профили или файлы окружения. Сборка готового приложения не означает автоматическое разрешение на распространение любого добавленного компонента.
