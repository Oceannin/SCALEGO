# Руководство SCALEGO

[← Скачать и познакомиться с приложением](../README.md)

## Первый результат

Добавьте изображения, выберите маршрут, настройте параметры и нажмите «Обработать». Готовое изображение можно сравнить с оригиналом до сохранения. Для нескольких файлов выберите нужные строки; «Сохранить все» экспортирует последние готовые результаты для исходников.

В просмотре: разделитель показывает до/после; **1:1** показывает пиксели; **Вписать** возвращает общий вид. **Колёсико мыши над изображением** увеличивает масштаб при прокрутке вверх и уменьшает при прокрутке вниз, без Ctrl; кнопки **+ / −** также доступны. При увеличении точка под курсором удерживается, пока это позволяют границы области просмотра. **Shift + перетаскивание** перемещает изображение поверх разделителя. Подложки помогают проверить прозрачные края.

## Увеличение

- **Фото · Естественно (Natural):** мягкая обработка фото, менее выраженные искусственные текстуры.
- **Фото · Детально (Detailed):** более сильная детализация фотографий; внимательно проверяйте лица и текст.
- **Иллюстрация · Чистые линии (Clean):** аниме, VTuber-графика, цифровые рисунки, чёткие границы и однотонные области. Сглаживает шум и может убрать мелкую текстуру.
- **Иллюстрация · Детально (Detailed):** подчёркивает детали и резкость рисунка.
- **Быстро (Fast):** быстрый AI-предпросмотр и лёгкая графика; качество на фотографиях ограничено.
- **Lanczos:** обычная интерполяция на CPU.
- **Nearest:** увеличение без сглаживания для пиксель-арта.

AI может изменить текст, тонкие детали и края. Альфа-канал увеличивается интерполяцией отдельно от RGB. Сравнивайте результат перед экспортом.

В пакете 0.2.0-alpha.1 включены все пять AI-моделей. Их файлы проверяются по SHA256; при повреждении или отсутствии модели приложение объясняет причину недоступности. Приложение не заменяет выбранную модель во время обработки. [Подробнее о составе](MODEL_AUDIT.md).

Natural и оба Detailed используют нативное 4× с одним качественным уменьшением для 2×/3×. Clean и Fast имеют собственные варианты 2×/3×/4×. Техническое имя и пояснение масштаба находятся в **«О модели»**.

## Сжатие

Качество работает для PNG, JPG, WebP и AVIF. Числа разных кодеков не означают одинаковое визуальное качество. Снижайте значение постепенно и сравнивайте изображение в масштабе 1:1.

**PNG:** при выключенном «Без потерь» приложение уменьшает палитру до 256 цветов или меньше. Возможны изменения оттенков даже при качестве 100. Прозрачность поддерживается, но её градации также могут измениться при квантовании. Если полноцветный PNG компактнее, выбирается он. С «Без потерь» сохраняются подготовленные пиксели; файл может совпасть с результатом обычного увеличения.

**JPG:** прозрачность заменяется выбранной подложкой, сжатие всегда с потерями. **WebP и AVIF:** доступны режимы с потерями и без потерь.

В «Ограничить вес файла» 0 означает отсутствие лимита. Приложение подбирает качество, не уменьшает разрешение. В режиме без потерь лимит только проверяется. Достижение любого размера и глобально оптимальный результат не гарантируются; невозможность уложиться показывается предупреждением.

## Ваши файлы и приватность

Изображения не отправляются на сервер. В приложении нет облачного аккаунта и телеметрии. Интернет нужен для первоначального скачивания приложения/зависимостей, а не для обработки.

Рабочая сессия находится в `%APPDATA%/scalego/`: `session.json` хранит состояние, `work/` — копии исходников, миниатюры и результаты. Portable использует тот же подход. Это данные на диске, а не временное содержимое только в памяти.

Удаление изображения из рабочей области удаляет его связанные рабочие данные; внешний оригинал и ранее экспортированные файлы сохраняются. После аварии могут остаться временные файлы. Перед ручной очисткой профиля закройте приложение и сохраните нужные результаты.

Рядом с экспортированным изображением создаётся JSON `.scalego` с параметрами и SHA-256. Для AI он также указывает движок, модель и её версию, запрошенный/нативный масштаб и промежуточное уменьшение. Это журнал обработки, импорт рецептов пока не реализован. Старые сессии совместимы: «Иллюстрации» сохраняют прежнее быстрое поведение, «Фотографии» — прежнюю детальную обработку.

## Требования и ограничения

- Windows x64; для AI — совместимый Vulkan GPU, актуальный драйвер и [Microsoft Visual C++ Runtime x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist). Microsoft OpenMP DLL не включена в публичный пакет; Runtime устанавливается отдельно с сайта Microsoft. Проверенная среда: Windows 11, NVIDIA RTX 4070 Ti SUPER. Это не полная матрица совместимости.
- Статичные PNG, JPEG, WebP и AVIF. Нет анимации, RAW и видео.
- До 200 исходников в рабочей области; 200 МБ и 40 Мп на исходник.
- Результат до 100 Мп и 32 768 px по стороне; реальный предел может быть ниже из-за памяти.
- Natural и Detailed: до 6,25 Мп исходника из-за промежуточного 4×. Native invocation ограничен пятью минутами; на очень медленном GPU уменьшите исходник.
- Выход — sRGB, 8 бит на канал, без исходных EXIF и ICC. «Без потерь» относится к подготовленным пикселям, не к исходному файлу, HDR или метаданным.
- Восстанавливаются последние 400 заданий. При штатном закрытии активные задания становятся прерванными; после запуска их можно повторить.
- Сборки не имеют цифровой подписи. Установщик собран, но полный сценарий установки/удаления NSIS не входит в автоматические проверки.

## Если что-то пошло не так

| Симптом | Что проверить |
| --- | --- |
| AI недоступен | В исходниках выполните `npm run engine:install`. В готовой сборке проверьте модели и Vulkan-драйвер. Выберите Lanczos для обработки без AI |
| Ошибка `VCOMP140.dll` | Установите Microsoft Visual C++ Runtime x64 по официальной ссылке выше; не скачивайте отдельные DLL с посторонних сайтов |
| Ошибка памяти | Уменьшите исходник или масштаб, освободите GPU, попробуйте обычное увеличение |
| PNG не стал меньше | Выключите «Без потерь», снизьте качество. Однотонная графика и уже оптимизированные файлы могут почти не уменьшиться |
| Увеличенный файл тяжелее исходного | В нём больше пикселей. Выберите «Увеличить и сжать», уменьшите качество или задайте лимит |
| Не достигнут лимит | Увеличьте лимит, смените формат или отдельно подготовьте меньший исходник |
| Пропала прозрачность | JPG её не поддерживает; используйте PNG, WebP или AVIF |
| Закрыли приложение во время обработки | Запустите снова и нажмите «Продолжить очередь» |
| Не удаётся сохранить | Выберите доступную для записи папку. Результат остаётся в рабочей области |

Если проблема повторяется, [создайте issue](https://github.com/Oceannin/SCALEGO/issues/new/choose). Укажите версию, Windows, GPU/драйвер, режим, формат и текст ошибки. Прикладывайте только обезличенные изображения, которые разрешено публиковать.
