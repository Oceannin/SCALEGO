# Аудит подготовки GitHub

Дата: 7 сентября 2026. Scope: готовность первой alpha к представлению и публикации; это адресный инженерный аудит, не независимый penetration test или юридическое заключение.

## Что проверено до оформления

- README, структура Git, исключения, ссылки, release-файлы и публичные утверждения.
- Источники `electron/main.cjs`, `preload.cjs`, `contracts.cjs`, `pipeline.cjs`, `engine.cjs`, сценарии установки моделей и подготовки релиза.
- Производственные и dev-зависимости через `npm audit`: 0 известных уязвимостей на момент проверки. Это снимок advisory-базы, не доказательство отсутствия дефектов.
- Reference: [BLURGO](https://github.com/Oceannin/BLURGO). Удачные элементы — результат перед устройством кода, реальные изображения, понятная загрузка, короткий старт и отдельные руководства.

MCP-граф в этой сессии недоступен (`Transport closed`); выводы сделаны по прямому чтению актуальных файлов. Полный графовый аудит вызовов не заявляется.

## Находки и решения

| Приоритет | Находка | Решение |
| --- | --- | --- |
| Высокий | Собственный код отмечен UNLICENSED; открытая лицензия не выбрана | Сохранить статус до решения владельца, не назначать MIT/GPL самостоятельно |
| Высокий | В локальной сборке есть Microsoft `vcomp140.dll`; прежние notices требуют подтвердить условия публичного распространения | Условия и источник требуют отдельного решения до публичной выдачи этого бинарника |
| Средний | Главная страница перегружена техническими деталями | README стал продуктовой страницей: польза, три задачи, реальный результат, загрузка и короткий старт |
| Средний | Исследования прежней архитектуры смешаны с текущими возможностями | Сохранены локально и исключены из публичного Git; текущая документация имеет отдельный индекс |
| Средний | Нет CI и стандартного способа сообщать об ошибке | Добавлены Windows checks, issue forms, PR template, CONTRIBUTING и SECURITY |
| Средний | `.env.*` не исключались | Добавлено исключение, `.env.example` допускается отдельно |
| Низкий | Ранний README ссылается на локальную сборку вместо GitHub Release | Подготовлены явный release URL и описание Portable/установщика/контрольных сумм |
| Низкий | Скриншот не показывает новую компрессию PNG | Использован настоящий screenshot PNG-обработки на собственном тестовом рисунке |

## Решение по оформлению

Основной язык — русский, как в приложении. Оранжевый акцент и тёмная обложка продолжают визуальный стиль SCALEGO. Обложка — собственный SVG, не изображение вымышленного интерфейса. Ниже показан настоящий интерфейс. Нет неподтверждённых обещаний улучшения качества, процентов экономии на любом файле, сравнений скорости с конкурентами и фиктивных значков статуса.

README ведёт пользователя от задачи к первому результату. Подробные ограничения, работа с файлами и форматами вынесены в USER_GUIDE; команды и архитектура — в DEVELOPMENT/APPLICATION. Обе группы доступны через docs/README.

## Границы и дальнейшие улучшения

- Проверенная среда пока одна: Windows 11 и RTX 4070 Ti SUPER. Нужны реальные проверки других GPU и установка/удаление NSIS.
- Метаданные и 16-bit/HDR не сохраняются. PNG с палитрой меняет оттенки; AI может менять текст и детали. Эти ограничения стоят рядом с соответствующими возможностями.
- Версия повторяется в нескольких местах; централизовать перед следующим релизом.
- CI подтверждает кодеки и сборку интерфейса; GPU/desktop не считается проверенным только по зелёному CI.
- Публикация исходников и бинарного выпуска проверяется отдельно. Подготовленный README сам по себе не подтверждает доступность release URL.
