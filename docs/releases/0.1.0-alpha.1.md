# SCALEGO 0.1.0-alpha.1

**Больше деталей. Меньше вес.** Первая alpha локальной мастерской изображений для Windows x64.

## Что можно сделать

- Увеличить иллюстрацию или фото в 2×/3×/4× с Real-ESRGAN либо использовать Lanczos/Nearest.
- Сжать PNG, JPG, WebP и AVIF с настройкой качества и лимитом веса.
- Объединить увеличение и сжатие в одной очереди.
- Сравнить до/после, проверить прозрачность и сохранить результат без перезаписи исходников.
- Вернуться к рабочей сессии и продолжить прерванную очередь.

В PNG доступно уменьшение палитры с поддержкой прозрачности и отдельный режим «Без потерь». Для небольшого файла начните с качества 85 и выключенного «Без потерь»; сравните оттенки перед экспортом.

## Пакеты

| Файл | Назначение |
| --- | --- |
| `SCALEGO-0.1.0-alpha.1-Portable.exe` | Запуск без установки |
| `SCALEGO Setup 0.1.0-alpha.1.exe` | Установщик с выбором папки |
| `SHA256SUMS.txt` | SHA-256 двух EXE |

Модели включены. Для AI нужны Vulkan-драйвер и [Microsoft Visual C++ Runtime x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist), установленный с сайта Microsoft. Microsoft OpenMP DLL не включена в пакет. Обычное увеличение и сжатие доступны без Vulkan. Portable хранит рабочие копии в профиле Windows. Сборки не подписаны цифровой подписью.

## Перед первым запуском

Скачайте один из EXE и `SHA256SUMS.txt` из этого выпуска. В PowerShell проверьте хеш командой `Get-FileHash -Algorithm SHA256 -LiteralPath './SCALEGO-0.1.0-alpha.1-Portable.exe'` и сравните его с соответствующей строкой. Откройте приложение, добавьте изображение, выберите маршрут, нажмите «Обработать», затем «Сохранить».

## Границы alpha

Проверено на Windows 11 / NVIDIA RTX 4070 Ti SUPER. Совместимость со всеми GPU не заявляется. NSIS собран, полный тест установки/удаления не выполнялся. Выход sRGB/8-bit без исходных EXIF/ICC. AI может менять детали; PNG с палитрой может менять оттенки. Нет анимации, RAW и видео. Лимит веса может оказаться недостижимым.

18 локальных тестов прошли; проверены frontend build, desktop workflow и запуск Portable.
