# SCALEGO 0.3.0-alpha.1

## What's new

- Russian and English interface localization.
- RU / EN language switcher with a persisted preference.
- Simplified processing workflow and clearer inspector hierarchy.
- State-aware Process, Save, Save selected, and Save all actions.
- Clearer batch-selection scope and result handling.
- Improved UI readability, preview backgrounds, and result-area layout.

## Fixes / UX

- Removed redundant success, system-status, and changed-settings messages.
- Removed the persistent AI model count and redundant route/status UI.
- Improved export behavior for one image, the current selection, and all finished results.

## Packages

- `SCALEGO-0.3.0-alpha.1-Portable.exe`
- `SCALEGO-0.3.0-alpha.1-Setup.exe`
- `SHA256SUMS.txt`

Windows x64. AI upscaling requires a compatible Vulkan GPU, a current graphics driver, and Microsoft Visual C++ Redistributable x64. Builds are not digitally signed.
